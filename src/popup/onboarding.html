    Make yourself heard

    Allow the microphone once. It’s only on when you ask.

  2. 02

    Press ⌘ ⇧ Space

    Start a command from any Chrome tab. Press again to cancel.

    Say what you’d like to do

    Try “search YouTube for quiet piano” or “bookmark this page”.
